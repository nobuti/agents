# Playbook: research

**Use when:** a question needs primary-source reading before deciding.

1. `/research` in a background agent: question stated, cited Markdown file written in the repo.
2. Read the file yourself; keep working meanwhile.
3. Feed it into `/grill-with-docs` (feature playbook step 1) if a build follows.

**Success evidence:** path of the research file; its sources checked (read, not trusted); the question answered or the gap named.
